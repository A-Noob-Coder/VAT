### 当前卡点 (唯一)

**DEV 轮真实产出未通过**。根因链 (已探明, 非引擎缺陷):

1. 中转网关 ALB 60s 硬切断 → 已解 (SSE 流式);
2. 中转的 glm-5.3-flash **强制深度思考** (`disableThinking` 被上游 400 拒绝), 全部输出走 `reasoning_content`, `content` 恒空 → 已解 (回退读取);
3. **致命项**: 大任务 (DEV 编码) 的思考流耗尽输出预算后以中间代码收尾, 最终 JSON 信封从未出现 → 解析失败 (已 4 轮加固: 16k 预算/思考简短指令/信封提取/裸换行修复, PM 级小任务已可走通, DEV 级仍不稳)。

结论: 与该模型的思考习惯对抗性价比低。**正确解法是用容灾链换模型** — 中转有 23 个模型, 探测哪些走正常 content 通道输出结构化 JSON, 换主力即可 (这正是容灾链设计存在的意义)。
